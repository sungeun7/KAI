# 재고이전 — CSM001 (192.168.0.37)

이 문서는 KAI 재고이전 흐름과 **add/Controllers/CSM001.cs**, **add/Models/CSM001.cs** (MACRO_WMS) API 형식을 함께 사용하는 방법을 설명합니다.

## 기본 URL

- **http://192.168.0.37/CSM001**
- `server/.env`에서 바꾸려면: `SAP_STOCK_TRANSFER_URL=https://다른호스트/경로`

## add/ CSM001 API 형식 사용 (MACRO_WMS)

`add/` 쪽 C# API는 다음 요청/응답 형식을 사용합니다.

- **요청:** `APIKEY`, `BizSeq`, `ReqList[]` (각 항목: `IfKey`, `WmsReqNo`, `ProcYmd`, `ProcHms`, `ProcUserId`, `ProdList[]` → `FrWh`, `ToWh`, `IfProdId`, `ProcQty` 등)
- **응답:** `HttpResult` ("S"/"E"), `HttpMessage`, `ResultList[]` → `Result`, `Message`, `ProcBundleNo`, `IfKey`

KAI에서 이 형식으로 보내려면 `.env`에 다음을 넣습니다.

```env
SAP_STOCK_TRANSFER_CSM001_FORMAT=true
SAP_STOCK_TRANSFER_URL=https://localhost:44346/CSM001
SAP_STOCK_TRANSFER_TLS_INSECURE=true
SAP_CSM001_APIKEY=emdc
SAP_CSM001_BIZSEQ=1
SAP_CSM001_USER=KAI
```

- `SAP_STOCK_TRANSFER_CSM001_FORMAT=true` 이면 KAI가 LLM으로 만든 proposal(FromWarehouse, ToWarehouse, Lines)을 **add/ 모델에 맞게** `APIKEY`, `BizSeq`, `ReqList`/`ProdList` 형태로 변환해 POST 합니다.
- 응답은 `HttpResult === "S"` 일 때 성공으로 처리하고, `ResultList[0].ProcBundleNo` 또는 `IfKey`를 문서번호로 표시합니다.
  - 로컬 Swagger가 `https://localhost:44346/swagger/index.html` 처럼 **자체서명 HTTPS**인 경우가 많아서, 연결 오류가 나면 `SAP_STOCK_TRANSFER_TLS_INSECURE=true` 를 켜야 합니다(개발용).

### DI 서버 경유 (권장)

192.168.0.37에 `/CSM001` POST가 없을 때, **DI 서버를 거쳐** 재고이전을 보낼 수 있습니다.

- `.env`에 **DI_SERVER_URL** 과 **DI_STOCK_TRANSFER_PATH** 를 설정하면, KAI는 **SAP_STOCK_TRANSFER_URL 대신 DI로만** POST 합니다.
- DI 서버가 같은 JSON을 받아 192.168.0.37의 실제 API(다른 경로/포트)나 SAP B1로 전달하면 됩니다.

```env
DI_SERVER_URL=http://192.168.0.37:8080
DI_STOCK_TRANSFER_PATH=/kai/stock-transfer
```

자세한 스펙은 `documents/DI_서버_연동.md` §3 참고.

## KAI → CSM001 POST

- **Method:** POST  
- **Content-Type:** application/json  
- **Authorization:** Basic (`manager`/`emdc` 또는 `SAP_USER`/`SAP_PASSWORD`)

### 본문 예시 (SAP B1 재고 이전 폼 기준)

폼 필드: **출고 창고**(AA120), **입고 창고**(AA100), **전기일/증빙일**, **시리즈**(주회), **회계 비고**, **품목 행**(품목번호, 수량).

```json
{
  "type": "KAI_STOCK_TRANSFER_V1",
  "program": "CSM001",
  "postedAt": "2025-03-18T...",
  "proposal": {
    "FromWarehouse": "AA120",
    "ToWarehouse": "AA100",
    "PostingDate": "2023-08-26",
    "DocDate": "2023-08-26",
    "Series": "주회",
    "JournalRemark": "재고 이전 -",
    "Lines": [
      { "ItemCode": "11411-053", "Quantity": 4, "ItemDescription": "" }
    ],
    "lgortFrom": "AA120",
    "lgortTo": "AA100",
    "matnr": "11411-053",
    "menge": 4
  }
}
```

CSM001(B1 연동) 쪽에서 `proposal`을 재고 이전 폼 값으로 채워 처리하면 됩니다.

## 사용 방법

- 입력에 **「재고이전」** 또는 **「재고 이전」** 이 **포함되면** 무조건 CSM001(`POST` 재고이전 URL) 경로를 탑니다.  
- 그 외 **이동전표·저장위치 이동** 등은 동작 키워드와 함께일 때 CSM001.  
- API: `POST /api/sap/stock-transfer` body `{ "instruction": "..." }`

## 시뮬

`SAP_STOCK_TRANSFER_MOCK=true` 이면 CSM001 호출 없이 DEMO 문서번호만 반환합니다.

## 포트 자동 시도

`http://192.168.0.37/CSM001` 처럼 **포트를 안 쓰면** KAI가 순서대로  
**8080 → 8000 → 8001 → 44300 → 80** 에 POST를 반복합니다(연결 거부·타임아웃일 때만 다음 포트).  
맞는 포트가 열리면 그 주소로 전송됩니다.

`.env`에서 순서 지정: `SAP_STOCK_TRANSFER_PORTS=8000,8080,80`

## 192.168.0.37 API 없을 때 — 테스트만 하려면

**KAI 서버에 테스트 수신 라우트**가 있습니다. 실제 B1(192.168.0.37) API가 없어도 **전송 성공**을 확인할 수 있습니다.

`server/.env` 에 다음 한 줄 추가 후 서버 재시작:

```env
SAP_STOCK_TRANSFER_URL=http://localhost:8080/api/csm001
```

이렇게 하면 재고이전 요청 시 **KAI 자신에게 POST**가 가고, `POST /api/csm001` 이 JSON을 받아 `docNo: TEST-xxx` 로 응답합니다.  
실제 192.168.0.37 연동이 준비되면 `SAP_STOCK_TRANSFER_URL` 만 그쪽 URL로 바꾸면 됩니다.

## `Cannot POST /CSM001` 가 나올 때 (192.168.0.37 사용 중일 때)

**포트·방화벽은 정상**이고, 서버까지 연결된 상태입니다.  
해당 서버(192.168.0.37)에 **경로 `/CSM001` 로 POST를 받는 API가 없다**는 뜻입니다.

- **할 일:** 192.168.0.37 서버 담당자에게 **재고이전 API의 실제 URL**을 확인하세요.  
  예: `http://192.168.0.37:8080/api/stock-transfer` 등 **경로·포트 포함**.
- 확인한 **전체 URL**을 `server/.env` 의 `SAP_STOCK_TRANSFER_URL` 에 넣습니다.

## 연결 안 될 때 (ECONNREFUSED)

- 전부 실패하면 응답에 **시도한 URL 목록**이 붙습니다.
- **방화벽·VPN·다른 망**이면 PC에서 브라우저나 `curl`로 같은 URL POST 테스트.
- **HTTPS + 자체서명**이면 `SAP_STOCK_TRANSFER_TLS_INSECURE=true` (개발용만).

## 플랜트 코드

AI가 `출고 플랜트 코드` 같은 문장을 넣으면 자동으로 `SAP_DEFAULT_WERKS_FROM` / `SAP_DEFAULT_WERKS_TO` (기본 1000)으로 바꿉니다.  
실제 플랜트가 다르면 `.env`에 `SAP_DEFAULT_WERKS_FROM=1100` 등 설정하거나 질문에 **「플랜트 1100에서 1200으로」**처럼 숫자로 적으세요.
