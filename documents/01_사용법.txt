KAI 사용 방법 (SAP 문서 기반 AI 질의응답)

1. 실행
   - run.bat을 더블클릭하거나 터미널에서 run.bat 실행
   - 문서 인덱싱은 run.bat으로 실행할 때만 수행됩니다

2. API 키 (선택)
   - OPENAI_API_KEY 환경변수에 OpenAI API 키 설정
   - 없어도 실행 가능하며, 설정 시 문서 기반 답변이 제공됩니다

3. 문서 넣기
   - documents 폴더에 .txt, .md, .json, .csv 파일을 넣으면 run.bat 실행 시 자동 인덱싱됩니다
   - SAP 분개/전표: 별도 폼 문서가 없어도, 아래처럼 넣을 수 있습니다.
     · 사용 절차·용어를 정리한 .txt 파일을 만들어 넣기
     · SAP에서 분개/전표를 CSV 등으로 내보낸 뒤, 그 파일을 documents에 넣기 (.csv 지원)
     · 필요한 내용을 복사해 텍스트 파일로 저장 후 documents에 넣기

4. 질문하기
   - 실행 후 콘솔에 질문 입력 후 Enter
   - 종료: quit 또는 exit 입력
